# Praktikum 1: Pertanyaan HTML Dasar

1. Apa fungsi deklarasi `<!DOCTYPE html>` pada dokumen HTML?  
   Jawab: Menyatakan bahwa dokumen menggunakan standar HTML5.

2. Apa perbedaan tag, elemen, dan atribut pada HTML?  
   Jawab: Tag adalah penanda elemen, elemen adalah struktur HTML yang terdiri dari tag dan isi, sedangkan atribut memberikan informasi tambahan pada elemen.

3. Apa perbedaan `<p>` dengan `<br>`?  
   Jawab: `<p>` digunakan untuk membuat paragraf, sedangkan `<br>` digunakan untuk membuat baris baru.

4. Apa fungsi atribut `href` pada tag `<a>`?  
   Jawab: Menentukan alamat atau tujuan tautan.

5. Apa perbedaan hyperlink internal dan eksternal?  
   Jawab: Internal mengarah ke halaman dalam website yang sama, sedangkan eksternal mengarah ke website atau domain lain.

6. Apa fungsi atribut `src` dan `alt` pada tag `<img>`?  
   Jawab: `src` menentukan lokasi gambar, sedangkan `alt` memberikan deskripsi alternatif gambar.

7. Apa perbedaan penggunaan `<ul>` dan `<ol>`?  
   Jawab: `<ul>` membuat daftar tidak berurutan, sedangkan `<ol>` membuat daftar berurutan.

8. Apa yang terjadi jika path gambar pada atribut `src` salah?  
   Jawab: Gambar tidak akan tampil karena browser tidak menemukan file pada lokasi tersebut.

9. Mengapa heading `<h1>` sampai `<h6>` perlu digunakan secara terstruktur?  
   Jawab: Untuk menunjukkan hierarki dan struktur informasi pada halaman.

10. Apa fungsi komentar `<!-- ... -->` dalam HTML?  
    Jawab: Memberikan catatan pada kode yang tidak ditampilkan oleh browser.
